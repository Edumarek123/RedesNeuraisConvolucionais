# Convolutional Neural Networks

An ongoing study project focused on extending a previously developed artificial neural-network library with convolutional neural-network capabilities for computer-vision applications.

## Overview

The project explores the implementation of convolutional neural networks and their integration with an existing neural-network codebase.

## Main topics

- Artificial neural networks
- Convolutional neural networks
- Computer vision
- Library development

## Development status

The original project notes describe the work as in progress. The implementation and supported operations may therefore be incomplete.

## Purpose

A learning project focused on neural-network architectures and the foundations of computer vision.
